# Қауіпсіздік тренажёры

«Қазақтелеком» АҚ жұмыскерлеріне арналған өндірістік қауіпсіздік бойынша сандық тренажёр (қазақ тілінде).

- 5 бейне-сабақ: наряд-рұқсат, ЖҚҚ, темірбетон тіректерді түсіру және орнату, тірекке көтерілу, кәбіл құдығындағы жұмыс
- Әр сабақтан кейін 4 сұрақтан тұратын тест (барлығы 20 сұрақ)
- Барлық сабақты өткенде қауіпсіздік сертификаты

Жасанды интеллект пен вайб-кодинг арқылы жасалған.

Дайындаған: жетекші инженер Шайдуллин А.С., Атырау қатынау желілерін пайдалану департаменті.
